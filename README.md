# Frontline

Mobile-first portrait PvP prototype built with Phaser, TypeScript and Vite.

## Current v0.1 loop

- 3-minute matches
- Three deployment lanes
- Moving frontline / territory pressure
- Core HP win condition
- Five-second breakthrough win condition
- Six unit archetypes with counter relationships
- Two abilities: Surge and Repulse
- Single-resource economy
- Aegis commander comeback passive
- Basic autonomous opponent
- Rematch flow
- Procedural prototype visuals with no third-party game assets

## Local development

```bash
npm install
npm run dev
```

Tap a unit card and then tap one of the three lanes to deploy it. Ability cards cast immediately.

The first prototype is intentionally focused on validating match flow, territory pressure, counters and pacing before art production or progression systems.
